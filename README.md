**[Install from Chrome Web Store →](https://chromewebstore.google.com/detail/stock-price-widget/niofpnhhdeaneajeemfpnclammlkhfg)**

---

## What it does

Place floating real-time price widgets anywhere on any webpage. Drag them around, resize them, pin them to the screen — they never block your clicks on the page below.

---

## Features

- **Real-time prices** — US stocks (NASDAQ / NYSE / AMEX), Korean stocks (KRX), crypto
- **Up to 3 widgets** on any webpage
- `Shift + drag` to place, move, and resize
- **Click-through** — the page underneath stays fully clickable
- Pin to viewport, minimize, hide/show per widget
- Right-click context menu (pin / delete)

---

## How to use

1. Click the extension icon → choose **Stock** or **Crypto** → search by ticker or name
2. Click **Create** → `Shift + drag` on the page to drop the widget
3. Right-click a widget to **pin**, **hide**, or **delete** it

---

## Supported markets

| Market | Search example | Real-time |
|--------|---------------|-----------|
| US Stocks (NASDAQ/NYSE/AMEX) | `AAPL.NAS`, `TSLA.NAS`, `NVDA.NYS` | ✓ |
| Korean Stocks (KRX) | `005930` or `삼성전자` | ✓ |
| Crypto | `BTC-USDT`, `ETH-USDT` | ✓ |

---

## Notes

- Does not work on `chrome://` internal pages.
- Crypto prices via Gate.io WebSocket.
- Korean stock prices via Korea Investment & Securities Open API.
